BSC DLP Community - ICACLS resilience hotfix v2

This version does not depend on an exact text match.
It locates the existing icacls ACL-hardening block using a tolerant regex,
creates a backup, and replaces only that block.

Result:
- icacls exists -> token ACL hardening is applied.
- icacls missing/fails -> explicit warning, startup continues.

Apply:
1. Extract into repository root.
2. Run APPLY-ICACLS-HOTFIX-v2.cmd
3. Run START-BSC-DLP.cmd

Backup created automatically:
scripts/windows/Start-Community.ps1.bak-before-icacls-hotfix
